Информация по установке и сборке
=======

Этот репозиторий можно использовать в качестве основы для изучения или сборки
модификации. Просто склонируйте его на свой компьютер и откройте в среде
разработки (настоятельно рекомендуется IntelliJ IDEA).

Если в какой-то момент в вашей IDE пропадут зависимости, сломаются импорты движка
или вы столкнетесь с ошибками сборки, вы можете выполнить команду:
`gradlew --refresh-dependencies` для принудительного обновления локального кэша.

Также вы можете использовать команду `gradlew clean`, чтобы полностью сбросить
все временные файлы сборки {это никак не затронет ваш исходный Java-код}, а затем
начать процесс компиляции заново.
